## 3. Methodology lessons (folded into the overlay in this change)

- **Fix-while-walking needs a convention.** Six of ten walkers found the working-tree fix via
  `git status` and split their verdict (HEAD vs working tree) unprompted. Recorded in the registry
  `LESSONS.md`; the overlay README now says a brief must state that the orchestrator may patch
  mid-run and ask for both grades.
- **The persistence rule is a data source with a residue check.** Ten creates on one profile exposed
  a theme minted per create — a defect no single walk could see. Now a method commitment (2.10) and a
  line in `uat/README.md`.
- **Severity vocabularies diverged across ten walkers** (P0–P4, blocker/major, high/low) despite the
  schema in the brief; the assembler normalised them. `uat/README.md` now carries a one-line legend
  walkers copy verbatim.
- **Three L2 harness assumptions came from the code, not the screen** (CSS-uppercased `innerText`;
  toggling tiles; the expert face on a return visit; hidden radios) and cost one rerun each. Recorded
  in `.claude/uat/config.md`; the standing rule is "probe the surface before asserting the L1
  picture of it".
- **What each level uniquely produced:** L1 owned the wiring audits (`grep targetS` → 0 hits,
  `grep reportPhase` → one caller) and every convergence; L2 owned reachability (the style wall), the
  residue defect (L2-1), one refutation (MA-L1-9), and the felt escalation in the voices (Priyanka's
  "refuse", Kwame's "glossary"). A surface-model gap L2 exposed: L1 never asked what the tenth
  create does to the shelves.
- **Schema hygiene held:** every fix carries `resolved-verified` + `recertify_evidence` + `ceiling`
  in the run's own `findings.json`, so §1 was a read, not a reconstruction.
