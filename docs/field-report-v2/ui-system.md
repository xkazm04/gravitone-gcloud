## 2. Deviations (nothing applied — read-only)

Both are LOW; there are no medium/high violations in this shard.

1. **`tooltip` P6 — native `title` fails WCAG 1.4.13 (dismissable/hoverable/persistent).** `Stepper.tsx:48`, `Playground.tsx:281`, `Playground.tsx:333` (and other `title=`). Native `title` cannot be dismissed with Escape without moving focus, cannot be hovered, and vanishes on a timer. **held: reason** — the info in every case is genuinely supplementary (P1 satisfied) and *also present as visible text or as an `aria-label`*, so no fact is tooltip-only; and native `title` does satisfy the more-often-missed P2/P3 (keyboard-focus reveal on a focusable element) that custom tooltips routinely botch. Severity LOW: acceptable for a prototype, but a future `<Tooltip>` primitive would close P6 across all sites at once.

2. **`empty-and-demo-states` — seed rows carry no visible "sample" mark.** `app/_studio/projectSeed.ts` ids `seed-*` render in `ProjectsView` indistinguishable from user projects. **held: reason** — the app declares its engine mocked on *every* surface (`LocalProcessNote`), and no aggregate is computed over the seed set that would silently become a "fact" (the specific hazard the clause guards). Severity LOW; a small `sample` chip would make it exact.
