## After the pass — what happens with this file

- Every **B win** = the rule goes to a second deck on fresh briefs; two wins → prompt card + registry technique (dated, provider-named).
- Every **A win** = the rule is declined *for this provider* and written down with your one line (negative evidence is the most reusable kind).
- **Ties** = the rule is model-indifferent here; it stays in the card only if it is free (costs no tokens).
- Keepers (+ their losing twins) → explanation pass: free checks first, Qwen only to describe why the winner won.
