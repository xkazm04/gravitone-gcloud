# Rebalance a script from feedback

## Goal (user POV)
"This draft spends too long in the wrong places. Let me say what I want changed,
in a few notes, and get back a version I can compare against the one I have —
and then decide whether to keep it."

## Definition of done (user POV)
1. I can leave several notes across different parts of the research.
2. One action turns all of them into a revised version. I do not answer notes
   one at a time.
3. I can see what actually changed, without diffing by eye.
4. I can tell whether the revision still holds up — same standard the original
   was held to.
5. I can accept it, or throw it away and keep my notes.

## Scenarios in scope
- S1 several notes on different tracks, one pass
- S2 contradictory notes on the SAME track ("more focus" + "descope")
- S3 a note that pushes the script over its runtime
- S4 a note on required material (the steel-man)
- S5 a note on material a turn depends on (wound graph)
- S6 free text the tool cannot act on
- S7 a second recalibration attempted while one runs
- S8 accept, then rebalance again from the new baseline
